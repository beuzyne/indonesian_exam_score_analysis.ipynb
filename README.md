# Indonesian Humanities Exam Scores and University Selection Analysis

An end-to-end data processing, feature engineering, and automated visualization pipeline analyzing 61,202 national student exam records and their respective university choices across Indonesia.

## Project Overview
This project executes a comprehensive data science lifecycle on a large-scale academic dataset. The objective is to automate the tracking of major selection behaviors across five top-tier universities, engineer unified student performance metrics, and perform structured population segment binning to classify national academic standings.

## Tech Stack and Skills Demonstrated
* Python: Core engineering, structural logic optimization, and loop automation
* Pandas: Multi-dimensional dataframe state construction, dynamic slicing, and row-wise average mutation
* Matplotlib and Seaborn: Advanced categorical data aggregation, automated bar charting, and industrial presentation layout styling

## Analytical and Data Pipeline
1. Data Loading and Inspection: Handled a large national test dataset containing 61,202 student records and 15 analytical columns.
2. Dynamic Loop Aggregation: Deployed an automated plotting function that loops through institutional codes to generate preference distributions for ITB, UI, UB, UNAIR, and UNP in a single execution.
3. Feature Engineering: Mutated a new unified performance metric (`final_score`) by dynamically calculating the mathematical mean across 9 distinct subject scores for each student.
4. Population Segment Binning: Classified raw student scores into structured academic categories (from '<300' up to '701-800') using continuous data distribution mapping.

## Key Insights and Portfolio Conclusions
* Institutional Preferences: Clear visual variance was discovered in student demand, highlighting strategic major hot-spots within specific regional economic zones (such as tech-focused centers vs law and social sciences hubs).
* Normal Score Distribution: The statistical binning successfully mapped a textbook bell-curve or normal distribution of student capabilities, with the vast majority of the 61,202 applicants falling strictly within the '501-600' average bracket.
* Professional Scalability: This architecture proves the capability to process tens of thousands of data entries seamlessly, demonstrating clean memory management and optimized code efficiency essential for enterprise data operations in Germany.
